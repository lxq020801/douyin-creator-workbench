## 目录说明

- `00_项目总览`：本项目的管理文档和统一判断。
- `01_核心资料`：13 份标记为最新版的 Markdown、DOCX 和 PDF。
- `02_研究底稿`：20 份分维度调研及交叉验证记录，用于追溯依据，不直接充当执行指令。
- `03_创作研发`：近期调研、竖屏风格样片、视觉评估与视频对标工具源码。
- `animation-lab`：Remotion 与 HyperFrames 两套隔离的竖屏动画实验环境。
- `videos`：正式视频项目源码；渲染结果和逐帧截图不进入 Git。
- `99_归档/旧版作废`：编导知识手册 v1，仅作历史参考。
- `99_归档/中间文件`：16 份转换稿、基础稿、HTML 和原调研计划，不作为当前版本。

## 版本规则

- Markdown 是便于继续维护的内容源；对应 DOCX 与 Markdown 已核验为内容等价，DOCX 主要用于排版和交付。
- `账号项目文档汇总` 除导航外，是其他五份最新版 Markdown 的拼接，不含额外决策。
- PDF 是汇总内容的 53 页排版成品，不是独立的新版本；其中仍同时保留了部分互相冲突的建议。
- `99_归档` 中的内容不得回写到当前方案，除非先说明采用原因并经本人确认。
- 下一轮校准后，应建立一份“唯一有效方案”，其他资料只做引用，避免多份“最新版”互相覆盖。
