# 今晚研究摘要

更新时间：2026-07-26

## 一句话结论

账号不应该做成“又一个展示 AI 动效的账号”。真正有辨识度的方向是：**用编导的判断组织证据，让真人、真实录屏、字幕和动画共处于一个持续变化的竖屏空间。**

## 今晚完成了什么

- 制作 10 个竖屏风格样片，统一为 1080×1920、30fps、6 秒。
- 每个样片都使用同一命题：`一个爆款 → 拆结构 → 换行业 → 生成 20 个选题`。
- 输出 10 个独立 MP4、30 张关键帧、三张阶段总览图和一个十画面同步总览视频。
- 建立本地选择页，可逐条播放、标记“喜欢 / 待定 / 不适合”、记录备注并导出选择。
- 核对 Remotion、HyperFrames、Hallmark 及国内外近期创作者工作流。
- 没有继续安装新动画框架；当前缺的不是工具，而是稳定的视觉语言和真实素材。

## 最重要的判断

1. **Remotion 作为长期主生产工具。**
   真人、录屏、字幕、参数化组件和批量复用更适合在同一 React 工程中管理。

2. **HyperFrames 作为快速实验工具。**
   HTML/CSS/GSAP 的自由度适合试风格、做短动效和特殊转场，但目前社区实战沉淀少于热度。

3. **Hallmark 和 huashu-design 都只当参考。**
   借它们的反模板意识、结构差异和自我审查，不照搬网页结构、主题轮盘和装饰配额。

4. **不新增 Motion Canvas、Rive、Revideo。**
   它们各有价值，但暂时不能解决“第一条视频如何形成账号记忆”这个核心问题。

5. **“动画全程存在”不等于“所有元素一直动”。**
   建议全程保留一条低频运动线索，每 1～2 秒只发生一个内容事件，同时只有一个高运动焦点。

## 我的先验推荐

不建议把某一套样片原样当成账号模板。最适合你的组合是：

- **A 清亮编辑部**：作为长期底盘和色彩基础。
- **B 导演时间线**：提供镜号、时间码、批注和编导身份。
- **H 产品纪录片**：决定真人与真实录屏的主从关系。
- **F 连续图解**：在概念高潮处，把一个结构变成多个选题。

可以概括成：**清亮编辑底盘 + 编导批注语言 + 真实录屏机制 + 一个持续变形的主元素。**

## 明天只需要决定什么

- 从 A～J 中选出 2～3 个“第一眼愿意继续看”的方向。
- 判断你更希望观众首先记住：你的判断、你的工具，还是你的表达气质。
- 允许组合，不需要在十套中机械地只选一套。

选定以后，再用真人素材和真实工具录屏做 15～20 秒练习片。今晚这些样片是视觉探针，不是第一条正式视频。
