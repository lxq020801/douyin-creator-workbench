# 十个竖屏风格样片

这批样片用于比较账号的视觉语言，不是第一条正式视频。十条都使用同一命题、同一时长和同一画幅，人物与工具界面暂时是结构占位。

## 直接开始

1. 打开 [账号风格选择台](index.html)。
2. 先播放 [十风格同步总览](10-style-overview.mp4)，凭第一感觉找出愿意继续看的方向。
3. 再逐条循环播放，标记“喜欢 / 待定 / 不适合”并写备注。
4. 点击“导出选择”，保留一份 JSON 结果。

选择会自动保存在当前浏览器的本地存储中。

## 当前推荐

不要机械地选一整套照搬。先验组合是：

**A 清亮编辑部的底盘 + B 导演时间线的身份语言 + H 产品纪录片的录屏机制 + F 连续图解的高潮动画。**

更完整的取舍见 [十个风格方向说明](../03_评估/十个风格方向说明.md) 和 [推荐视觉系统](../03_评估/推荐视觉系统.md)。

## 正式练习片的边界

- 替换为本人真人素材和选题工具的真实录屏。
- 不使用样片中的人物剪影和虚构 UI 作为正式证据。
- 先做 15～20 秒练习片，验证手机可读性、真人占比和实际制作耗时。
- 动画全程存在，但同一时刻只保留一个高运动焦点。

技术规格：`1080×1920`、`30fps`、`180 帧`、`6 秒`、H.264。
