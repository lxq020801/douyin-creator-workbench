# Changelog

## v0.3.0-dev - 2026-07-28

本地完整产品候选版，尚待有效模型配置与抖音 Cookie 下的真实链接验收。

### Added

- 账号主页采集 50 条作品与 30 条均衡视频深拆。
- 高表现、近期和常态样本组合，以及元数据覆盖说明。
- 账号综合报告和账号对标选题。
- 一句话账号资料、必要追问、资料卡确认与多份保存。
- 选题编辑、单选/多选/全选脚本任务、失败项单独重试。
- 三个独立 RQ Worker、任务恢复、取消、重试和删除。
- 报告长图导出、完整脚本查看与复制。
- Docker Compose 本地运行环境和 Redis/数据库就绪检查。

### Security

- API Key 和抖音 Cookie 保存在本机数据库，设置页直接显示完整内容。
- 诊断信息脱敏，视频和运行时数据不进入 Git。

## v0.2.0 - 2026-07-27

### Added

- 单条抖音链接解析、元数据读取、视频下载和模型拆解闭环。
- 拆解报告、20 个选题和编导可拍稿脚本结构。
- FastAPI、SQLite、真实历史记录与工作台 API。
- 管理设置、模型连接测试和抖音 Cookie 有效性测试。

## v0.1.0 - 2026-07-26

### Added

- 首页、工作台、结果页、账号资料弹窗和管理员设置的前端视觉原型。
