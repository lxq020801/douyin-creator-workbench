# 视频对标工具

当前产品用于把抖音单条视频或账号主页转成可追溯的编导拆解报告，并在用户确认账号资料后生成可执行的对标方向。

## 当前状态

版本：`v0.1.0` 前端视觉原型。

- 已完成首页、工作台、两类报告、账号资料弹窗和管理员设置的前端设计。
- 已验证模型配置可以真实调用火山方舟 Responses API。
- 抖音采集、视频下载、模型文件处理、任务持久化和真实复刻尚未接入。

## 目录

- `app/`：React + TypeScript + Vite 前端应用。
- `项目方向草案.md`：产品目标、用户流程和接入边界的讨论稿。

后续后端代码接入时，应在本目录内建立独立服务目录，不把 Agent-wiki 或抖音策划台整个仓库复制进来；只迁移经过确认的模块和依赖。

## 前端运行

```bash
cd app
npm install
npm run dev
```

本地地址：`http://127.0.0.1:4178`
