# 参考系

短视频对标与选题工作台。当前版本完成了产品的完整前端流程和本地状态管理，后端能力等待从抖音策划台与 Agent-wiki 接入。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:4178`

## 检查与构建

```bash
npm run check
npm run build
```

## 当前流程

- 单条视频：抖音链接输入、处理状态、拆解报告、长图导出、选择账号资料、生成复刻产物。
- 账号主页：全量深拆或智能取样、时间和成本确认、账号打法地图、样本筛选与证据报告。
- 账号资料：自然语言描述、必要追问、资料卡确认、新建和编辑。
- 管理设置：模型与 API、抖音 Cookie、视频参数和五类系统提示词。
- 历史任务：筛选、打开和失败任务重试。

## 接入边界

页面中的分析数据和处理进度目前由本地样例驱动。正式接入时复用旧项目已经跑通的链接解析、主页采集、视频下载、豆包多模态分析、任务轮询与配置存储能力，不再重做这部分后端逻辑。
