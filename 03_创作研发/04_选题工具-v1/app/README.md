# 视频对标工具前端

短视频对标与选题工作台的 React 前端。当前版本完成了主要页面的视觉原型和基础交互，业务数据仍由本地样例驱动。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:4178`

## 检查与构建

```bash
npm run check
npm run build
```

## 已完成的前端页面

- 首页：单条视频与账号主页入口。
- 工作台：历史记录、筛选和搜索原型。
- 结果页：单条视频拆解报告、账号研究报告和复刻入口。
- 账号资料：自然语言描述、必要追问与资料卡确认原型。
- 管理设置：模型与 API、抖音 Cookie、视频参数和系统提示词。

## 接入边界

页面中的报告、历史记录和账号资料目前由本地样例驱动。正式接入时复用旧项目已经跑通的链接解析、主页采集、视频下载、豆包多模态分析和任务轮询能力，并把敏感配置移到服务端保存。

当前前端不会验证模型或 Cookie 是否真实可用，也没有完成任务持久化。页面中的“配置完整”只代表必填字段已填写。
