# 维度调研报告（启航 · DIM-01）

调研时间：2026年（基于2025–2026年公开报道与榜单）
调研方法：中文网络搜索 30 组独立关键词（覆盖"AI工具博主 / AI提效账号 / AI自媒体教学 / 用AI做短视频的博主 / AI工作流博主 / 编导转行AI / 做工具的博主 / 对标拆解工具博主"等），重点参考行业媒体（虎嗅、澎湃/壹娱观察、36氪、中国企业家、北京青年报）、第三方数据（蝉妈妈）、垂类榜单（AIGCRank 2025年度AI博主榜单）。

## 维度：AI工具类账号竞争格局

### 关键发现

1. **赛道已形成清晰的"四分法"格局，"AI工具测评与科普"是最大、最拥挤的一类。** 据壹娱观察/虎嗅对抖快红B四平台AI创作者的盘点（2026年5月），AI博主分为四类：AI工具测评与科普、AIGC创作、虚拟人/数字人、硬核技术与开发；其中"AI工具测评与科普"被定义为"最常见也最能起量的类型"，靠追新工具热点获取流量[^1^]。

2. **头部账号走"选品权威+商单"路线，粉丝量级在百万级但天花板已现。** 代表"秋芝2046"全网粉丝近250万（抖音单平台约138–143万），主打AI产品测评与功能演示，已接钉钉AI录音卡、豆包、飞书等厂商商单；但虎嗅2026年5月的跟进报道指出"第一届AI博主已经碰到赚钱天花板"，垂类受众对商单敏感、变现想象力受限[^2^][^3^]。

3. **变现四路径高度定型：品牌商单、收徒卖课、付费社群/知识付费、平台分成。** 其中"收徒与卖课"被行业媒体称为"中腰部创作者的现金流工厂"——如"LT小狗日记【收徒】"靠几百元一套的AI短剧变现课获利，本质是"借AI造富神话收割知识焦虑"[^1^]。DeepSeek爆火期，知识博主"老徐"的"用DeepSeek赚小钱"社群4天入账近20万元、成员超6000人[^4^]。

4. **"教自媒体同行用AI解决内容生产痛点"这一细分已被大量占据，但交付物几乎全部是"信息"而非"工具"。** 具体证据：
   - 选题/文案/对标拆解已成为AI自媒体教学的标配内容：大量博主、公众号教程教"用Kimi 10秒拆解对标账号""DeepSeek生成选题+广告报价"[^5^][^6^]；
   - 扣子（Coze）工作流教程类账号（如"大熊老师""吾鳴"）已把"自动采集抖音/小红书对标账号→拆解文案→写入飞书"做成保姆级系列内容，且以引流卖课/社群收尾[^7^][^8^]；
   - **平台方和工具方亲自下场**：新榜联合扣子官方推出"小红书账号分析智能体"，蝉妈妈把"对标账号拆解、爆款脚本仿写"做成产品内置功能——对标拆解这一痛点正在被免费/低价的标准化工具直接消化[^9^][^10^]。

5. **同质化最严重的角度：提示词合集、工具盘点、"保姆级教程"、卖课收徒。** 小红书2025年上半年处置虚假低质AIGC笔记60万篇，2026年已建立针对"AI率、同质化、低创作"的多模型审核体系；大量"全网首发100条提示词"类账号活跃几天即消失[^11^][^12^][^4^]。行业共识是"AI内容创作、软件工具开发"已成一人公司/超级个体涌入最多、同质化最严重的赛道[^13^]。

6. **"编导/内容专业背景 + 现场用AI写代码做可交付的网页工具 + 面向同行收定制费"这一组合，未发现占位者。** 针对性搜索"编导转行AI博主""做工具的博主·定制网站变现""教编导/教运营用AI·口播"等关键词均无有效结果。最接近的三类邻居是：
   - AI超级个体/独立开发类（花叔、刘小排r、哥飞等）：确实"用AI做产品"，但面向开发者/出海人群，不服务自媒体同行的内容生产场景[^14^]；
   - 工作流教程类：做Coze/n8n演示，但目标是引流卖课，工具多为模板复用而非按需定制，且人设是"效率博主"而非"懂内容的编导"；
   - 自媒体教学类：懂选题/拆解/文案方法论，但只做口播方法论，不做工具交付。

7. **视频号是明显的内容洼地。** 视频号上的"AI+变现"内容集中在面向中老年流量的玩法（AI语录号、国学号、怀旧带货号），面向自媒体同行的AI工具教学供给显著少于抖音/小红书；视频号创作者分成计划门槛仅100粉，生态仍处"2018年抖音"式的红利期[^15^][^16^]。

### 同质化与空白点

**同质化重灾区（不建议正面进入）：**
1. **工具盘点/测评**：新工具一发、全网同质内容刷屏，秋芝2046类头部已占住"选品权威"心智，且面临商单天花板[^1^][^3^]；
2. **提示词合集**：李继刚、歸藏等已封神，低价提示词包账号被平台批量治理[^4^][^11^][^14^]；
3. **"保姆级"通用教程 + 引流卖课**：供给过剩、信任透支，"割韭菜"报道频发，用户对卖课型账号警惕性显著上升[^1^][^18^]；
4. **AI批量起号玩法**（语录号、萌宠短剧、ASMR）：平台专项治理+标识新规，红利窗口关闭中[^19^][^20^]。

**空白点（机会区）：**
1. **"交付工具而非交付信息"**：AI教学类账号全部停留在教方法/卖模板，没有账号以"现场做出一个可直接使用的网页工具并送给你"作为内容本体；自媒体同行工具（选题库生成器、对标拆解报告器、文案诊断器）目前只有蝉妈妈/新榜等企业级付费产品和零散的Coze模板，缺乏"人味"的创作者品牌[^7^][^9^][^10^]；
2. **"编导视角"**：懂选题会、拆片、脚本结构的内容专业者做AI工具内容的账号几乎为零——现有AI博主多为产品经理/程序员/运营背景，内容生产方法论维度浅；
3. **B2B式同行服务人设**：面向"自媒体同行"（有付费能力的专业受众）而非"想搞钱的小白"，做定制工具变现的账号形态未见代表者；
4. **视频号同行向AI内容**：供给显著稀缺，且视频号用户对"微信生态内可用的小工具"天然适配（转发即用）[^15^]。

### 对该定位的含义（机会与威胁）

**机会：**
1. **定位正落在空白交叉带上**——"编导专业方法论（选题/文案/对标拆解）× AI现场构建工具 × 同行受众"三者交叉处无占位者；最接近的竞争者要么只教不做（教学类），要么只做不教（独立开发类），要么只做平台模板不做定制（工作流类）[^7^][^14^]。
2. **变现路径差异化成立**：主流变现（卖课/社群/商单）已拥挤且信任受损，"定制网页工具"是服务化、高客单、低同质的路径，且"内容即案例"——每条口播+录屏视频本身就是销售演示，天然规避"割韭菜"质疑[^1^][^18^]。
3. **"做工具的人"人设有记忆点**：赛道内人设高度趋同（测评者、布道者、卖课者），"干活的手艺人"人设在同质化环境中辨识度强；编导背景可支撑"我懂你的痛点因为我干过这行"的信任叙事。
4. **平台供给缺口**：视频号同行向AI内容稀缺，可作为冷启动侧翼；抖音/小红书主打录屏实操类内容仍有工具型流量红利（单条教程类视频可获12万+收藏的记录）[^15^][^21^]。

**威胁：**
1. **大厂/平台免费工具的快速吞噬**：新榜×扣子的账号分析智能体、蝉妈妈的对标拆解功能表明，"选题/拆解"类痛点正被免费标准化产品消化；自制定制工具必须做到"平台工具不愿做的个性化深度"，否则会被零成本替代[^9^][^10^]。
2. **AI能力平权**：Coze/扣子编程等零代码工具让"做工具"本身的门槛持续降低，竞对可复制形式；护城河必须落在编导方法论+行业理解+定制服务关系上，而非"会用AI写代码"这一技能本身[^7^][^8^]。
3. **受众对"AI教学账号"的疲劳与警惕**：卖课型账号的信任危机可能外溢——需在内容上明确与"收徒卖课"划清界限（如不挂课、直接送工具、明码标价做定制）[^1^][^18^]。
4. **AI内容平台治理收紧**：小红书/抖音对AI率、同质化的审核趋严，纯AI生成的内容会被限流；口播真人出镜+真实录屏的形式恰好合规友好，但需避免模板化批量产出[^11^][^12^][^19^]。
5. **需求验证风险**：自媒体同行是否有为定制网页工具付费的意愿与预算，公开信息中无直接数据支撑，建议以低价小工具（选题库、拆解报告器）先行验证付费转化。
